# Changelog

## 1.0.0

Initial standalone SDK: Rust core, Node.js/TypeScript, Python, .NET, C ABI and JSON CLI. Pythagorean name/birth numbers, calendar cycles, pinnacles, challenges, bounded Essence transits and derived values. Explicit reference date, structured culturally neutral name parts, master-number/Y configuration, reduction traces and versioned rules. Unsupported systems and characters return errors. MIT, Copyright (c) 2026 7mlabs. No dependency on Swiss Ephemeris or the Astro SDK.

This is a new SDK contract; legacy HTTP-service payloads are not an existing SDK compatibility contract. Chaldean is planned for a later release.
